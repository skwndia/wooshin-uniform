반영 기능
1. 학교 로고 기본 적용
2. 사업 안내 / 신청 가능 시간 자동 표시
3. 교복 대여 신청
   - 학번 / 이름
   - 품목 + 사이즈 + 수량 복수 선택
   - 일시 대여 / 영구 수령 선택
   - 일시 대여 시 대여 시작일 / 반납 예정일 / 반납 예정 시간
   - 화·목 수령일 선택
4. 교복 물려주기 신청
   - 학번 / 이름
   - 품목 + 사이즈 + 수량 복수 선택
   - 화·목 전달일 선택
5. 보유 교복 목록
   - 품목별 사진
   - 사이즈별 수량
   - 품절 / 대여 가능 표시
6. 관리자
   - 품목별 사진 등록 / 삭제
   - 새 품목 / 사이즈 추가
   - 사이즈별 재고 +/- 조정
   - 대여 / 물려주기 신청 학년별 조회
   - 지급 완료 시 재고 감소
   - 전달 완료 시 재고 증가
   - 완료 신청 삭제
7. 홈 화면 추가(PWA)
8. QR코드 포함

중요
- 현재는 최종 프런트엔드 시제품입니다.
- 신청 / 재고 / 품목사진 / 로고 변경 데이터는 localStorage에 저장됩니다.
- 학생 여러 명이 동시에 사용하는 실제 운영 전에는 공용 DB(Baserow 등) 연결이 필요합니다.
- 관리자 비밀번호 또한 실제 운영 전에는 안전한 인증 방식으로 교체해야 합니다.
